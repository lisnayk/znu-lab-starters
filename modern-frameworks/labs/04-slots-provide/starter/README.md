# Зразок оформлення вкладок до лабораторної роботи № 4

Це готовий вигляд компонента вкладок і більше нічого. У проєкті один компонент
`TabsDesign.vue` зі статичною розміткою: активною показано першу вкладку, дві
інші панелі приховано модифікатором класу. Перемикання, контексту
`provide/inject`, реєстру вкладок і клавіатурної навігації тут немає — це і є
зміст лабораторної роботи.

Проєкт самостійний. До каталогу `lab4` його не копіюють: звідти беруть розмітку,
назви класів і стилі.

## Походження розмітки

Склад елементів узято з прикладу
[Tabs with Automatic Activation](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/examples/tabs-automatic/)
збірника WAI-ARIA Authoring Practices Guide. Збережено ролі `tablist`, `tab` і
`tabpanel`, зв'язки `id` з `aria-controls` та `aria-labelledby`, доступну назву
списку через заголовок, а також `aria-selected` і `tabindex`, якими передано
активність. Змінено класи, бо оригінал оформлено селекторами за атрибутами, і
текст вкладок, бо приклад описує данських композиторів.

## Запуск

Команди виконуються з каталогу стартера:

```bash
npm ci
npm run dev -- --port 5173 --strictPort
```

Сторінка відкривається за адресою `http://localhost:5173/`. Готова збірка
перевіряється командою `npm run build`.

## Склад файлів

- `index.html` — точка входу Vite;
- `src/main.js` — створення застосунку та підключення спільних стилів;
- `src/assets/main.scss` — директиви Tailwind CSS;
- `src/App.vue` — сторінка зі зразком;
- `src/components/tabs/TabsDesign.vue` — розмітка та стилі вкладок;
- `tailwind.config.js`, `postcss.config.js`, `vite.config.js` — налаштування
  Tailwind CSS 3.4.17, PostCSS і складання;
- `package.json`, `package-lock.json` — залежності, серед них Sass.

## BEM і SCSS

Класи названо за методологією BEM:

- блок: `tabs`;
- елементи: `tabs__title`, `tabs__list`, `tabs__tab`, `tabs__label`,
  `tabs__panel`, `tabs__text`;
- модифікатори: `tabs__tab--active`, `tabs__panel--hidden`, `tabs--underline`.

Стилі лежать у `<style scoped lang="scss">` самого компонента. Значень кольорів,
розмірів і відступів у них немає: вигляд зібрано з утиліт Tailwind CSS через
`@apply`, тому в шаблоні не з'являються довгі набори utility-класів. Вкладеність
SCSS і змінна `$self` дають змогу описати варіант оформлення модифікатором
блока, а не складанням назви класу в шаблоні.

Смуга кнопок не прокручується: за браком місця вкладки переносяться на
наступний рядок, тому жодна з них не лишається поза екраном.

## Кольори і шрифти

Назви кольорів `ink`, `surface`, `edge`, `muted`, `paper` та `accent`, а також
родини `display` і `body` описано один раз у `tailwind.config.js`. Значення
перенесено зі спільної теми курсів, де акцентом цього курсу є бірюзовий колір
сервера. Основний текст подано кольором `ink`, другорядні написи — `muted`, а
акцент несе лише смужка активної вкладки: бірюзовий на білому не дає
потрібного контрасту для тексту.

Шрифти `Unbounded` для заголовків та `IBM Plex Sans` для прози підключено в
`index.html` з Google Fonts. Без мережі підставляються запасні `Cambria` і
`Calibri`, а розкладка від цього не змінюється.

## Що робить студент

- Переносить розмітку й стилі до власних компонентів `Tabs.vue` і `Tab.vue`
  проєкту `lab4`, замінивши сталі `id` та `aria-selected` обчисленими
  значеннями.
- Додає варіанти `tabs--pills` і `tabs--boxed` за зразком `tabs--underline`.
- Реалізує автоматичну активацію, контекст вкладок і збереження локального стану
  панелі за ходом роботи.
