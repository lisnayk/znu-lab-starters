# Статична заготовка лабораторної роботи № 2

Це готова верстка каталогу навчальних матеріалів. У ній навмисно немає Vue,
залежностей, засобів складання та JavaScript-логіки: `index.html` підключає
лише `styles.css`. Файл `materials.js` містить тільки вихідні дані шести
карток і не підключений до статичної сторінки. Елементи форми й кнопки
показують майбутній інтерфейс, але ще не фільтрують дані та не змінюють стан.

## Перегляд

Відкрийте `index.html` у браузері. Для перевірки статичної верстки сервер і
встановлення пакетів не потрібні.

## Карта компонентів

Коментарі `Компонент ...: початок` і `Компонент ...: кінець` у `index.html`
позначають межі майбутніх Vue-компонентів:

- `App.vue` — композиція сторінки та підключення каталогу;
- `MaterialCatalog.vue` — застосовані фільтри, результати й вибраний матеріал;
- `MaterialFilterForm.vue` — локальний стан полів і події `apply` та `clear`;
- `MaterialCard.vue` — одна картка, її пропси та подія вибору.

Коментарі `TODO` вказують, яку частину потрібно зробити реактивною. Після
перенесення розмітки до SFC ці навчальні коментарі можна видалити.

Скопіюйте `materials.js` до `src/data/materials.js` створеного Vue-проєкту.
Структуру та вміст масиву змінювати не потрібно.

## BEM

Класи оформлено за методологією BEM:

- блок: `material-card`;
- елемент: `material-card__title`;
- модифікатор: `material-card--vue`.

Під час перенесення розмітки не змінюйте класи без потреби: готовий CSS уже
описує адаптивний вигляд і стани фокуса. Спільні стилі можна підключити у
`src/main.js`, а межі компонентів визначаються HTML-коментарями, а не файлами
стилів.
