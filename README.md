# Заготовки до лабораторних робіт

Стартові проєкти лабораторних: збірка, залежності й порожні місця, які треба заповнити. Розв'язків тут немає й не буде.

Це дзеркало, а не місце для роботи. Правки робляться у джерелі й
приїжджають сюди наступною публікацією.

[Правила структури й оформлення](RULES.md).
